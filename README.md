# Color_Guesser

The game is inspired by Lightspark's game "color". The user will be shown a random color for a few seconds. Then the user must adjust 3 sliders (one for each RBG channel) to match the color previously shown. The closer the user is to the original color the more points they will get. This will be done for 5 total rounds

Multiplayer: once a user starts a game, any other user can join within 15s. At the end, their scores will be sorted and the greatest will be declared the winner.

Languages: C and Python
